# Contracts in this showcase

These are selected versioned contracts and manifests from Ayni. The connector and capsule schemas define boundaries between agent capabilities and their host. The execution and Judge port descriptions focus on harness/model exchange and semantic assessment.

Manifest examples show declared pins and required host ports. The Core service, registry, deployment loader, connector dispatch, and authorization implementation are intentionally not included. These files document the architecture; they do not create an executable deployment.

The fixtures use synthetic identifiers and sample organization evidence. They contain no customer records or provider credentials.
